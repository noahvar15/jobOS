# JobOS

JobOS is a full-stack job search management platform designed to help job seekers manage their applications, companies, contacts, interviews, follow-ups, and job-search analytics in one place.

The project is being built as a real application rather than a mock portfolio project.

## Goals

JobOS aims to provide a centralized place to manage the job search while providing practical experience with modern software engineering.
